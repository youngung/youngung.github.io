  • 벡터의 크기와 단위벡터를 구할 수 있다.
  • 내적을 이용하여 두 벡터의 수직 여부와 끼인 각을 구할 수 있다.

9·10장에서 배열을 저장하고 축별로 계산하는 방법을 배웠다. 이번 장에서는 1차원 배열의 값이 한 벡터의 성분을 나타낼 때, 합·크기·내적·외적에 어떤 수학적 의미가 있는지 살펴본다. 다음 12장에서는 이 내적을 바탕으로 행렬–벡터곱을 구성한다.

2. 벡터와 NumPy 배열

벡터(vector)는 크기(magnitude)와 방향(direction)을 함께 나타내는 물리량이다. 3차원 벡터 $\boldsymbol a$는 다음과 같이 세 성분으로 나타낼 수 있다.

\[[\boldsymbol a]= \begin{bmatrix} a_x\\a_y\\a_z \end{bmatrix}\]

1차원 NumPy 배열로 벡터를 아래와 같이 나타낼 수 있다.

import numpy as np
a = np.array([3.0, 4.0, 5.0])
print(a)
print(a.shape)
print(a.ndim)
print(a.size)

벡터 성분은 앞선 강의에서 배운 인덱싱(indexing)으로 선택한다.

print(a[0])
print(a[1])
print(a[2])

위의 배열 a는 1차원 배열이었다. 아래는 2차원 배열이다. 둘을 구분할 수 있어야 한다.

import numpy as np
a = np.array([[3.0], [4.0], [5.0]])
print(a)
print(a.shape)
print(a.ndim)
print(a.size)

2.1. 벡터 자체와 좌표성분 구분하기

온도(temperature)는 하나의 값으로 나타내는 스칼라(scalar)이고, 힘(force)과 변위(displacement)는 방향도 필요한 벡터다. 벡터의 성분을 쓰려면 먼저 기준 방향인 기저벡터(basis vector)를 정해야 한다. 서로 수직이고 길이가 1인 기저($\boldsymbol e_x, \boldsymbol e_y, \boldsymbol e_z$)를 사용하면

\[\boldsymbol a=a_x\boldsymbol e_x+a_y\boldsymbol e_y+a_z\boldsymbol e_z\]

로 쓴다. 예를 들어 $\boldsymbol a=3\boldsymbol e_x+4\boldsymbol e_y$는 첫 번째 방향으로 3, 두 번째 방향으로 4만큼의 성분을 갖는다. 좌표축을 바꾸면 같은 벡터도 성분값이 달라질 수 있지만, 벡터의 크기와 물리적 의미는 유지된다. 이 강의의 길이·내적 공식은 같은 직교정규 기저(orthonormal basis)에서 표현한 실수 성분에 적용한다.

그림의 오른쪽에서는 기저를 반시계 방향으로 $90^\circ$ 회전했다. 새 기저는 $\boldsymbol e’_x=\boldsymbol e_y$, $\boldsymbol e’_y=-\boldsymbol e_x$이므로, 같은 벡터를 $\boldsymbol a=4\boldsymbol e’_x-3\boldsymbol e’_y$로 나타낸다. 화살표는 그대로지만 좌표성분은 $(3,4)$에서 $(4,-3)$으로 바뀐다.

측정값 세 개를 배열에 저장했다고 해서 반드시 공간상의 벡터인 것은 아니다. 서로 다른 세 시편의 온도를 저장한 배열과 한 힘의 세 방향 성분을 저장한 배열은 모양이 같아도 의미가 다르다. 배열을 만들기 전에 각 원소의 의미와 단위를 먼저 적자.

2.2. 1차원 배열과 행·열 배열의 차이

수식에서 벡터를 세로로 쓰더라도, 코드에서 만든 배열이 자동으로 2차원 열 배열이 되는 것은 아니다.

vector = np.array([3.0, 4.0, 0.0])
column = vector[:, None]
row = vector[None, :]
print(vector.shape, column.shape, row.shape)
print(vector.T.shape)

결과는 각각 (3,), (3, 1), (1, 3)이며, 1차원 배열의 .T는 shape을 바꾸지 않는다. 특히 vector + column은 브로드캐스팅 때문에 (3, 3) 배열이 된다. 성분별 덧셈을 의도했다면 두 배열을 모두 (3,)으로 맞춰야 한다.

인덱싱에서 None의 역할

10장 6.1절과 8절에서 배운 것처럼, None은 길이가 1인 새 축을 추가한다. vector[:, None]은 열 배열, vector[None, :]은 행 배열을 만든다. 여기서는 벡터 계산에 사용할 배열의 shape을 구분하는 데 집중하자. 수학적 벡터를 열벡터로 써도 NumPy에서는 (3,) 배열로 계산할 수 있다.

3. 벡터의 합과 차

두 벡터의 합과 차는 같은 위치의 성분끼리 계산한다.

\[[\boldsymbol a]+[\boldsymbol b] = \begin{bmatrix} a_x+b_x\\ a_y+b_y\\ a_z+b_z \end{bmatrix}\] 
a = np.array([3.0, 4.0, 5.0])
b = np.array([3.0, -5.0, -2.0])

vector_sum = a + b
vector_difference = a - b

print(vector_sum)
print(vector_difference)

결과는 각각 $[6,-1,3]$과 $[0,9,7]$이다. 벡터의 대응 성분끼리 더하고 빼려면 두 입력을 같은 shape의 1차원 배열로 준비하자. shape이 다르면 브로드캐스팅에 의해 의도와 다른 결과가 나올 수 있다.

그림은 기하학적 의미를 보기 위한 별도의 2차원 예제다. $\boldsymbol a=(3,1)$, $\boldsymbol b=(1,2)$일 때 합은 $(4,3)$, 차는 $(2,-1)$이다. 합을 구할 때는 $\boldsymbol a$의 끝점에 $\boldsymbol b$의 시작점을 옮겨 붙인다. 이때 벡터의 길이와 방향은 유지한다. 차는 $\boldsymbol a+(-\boldsymbol b)$로 계산한다. 두 벡터를 같은 시작점에서 그렸다면 $\boldsymbol b$의 끝점에서 $\boldsymbol a$의 끝점으로 향하는 화살표도 $\boldsymbol a-\boldsymbol b$를 나타낸다. 순서를 바꾸면 차의 방향이 반대가 된다.

4. 벡터의 크기

벡터 $\boldsymbol a$의 크기, 즉 유클리드 노름(Euclidean norm)은

\[\|\boldsymbol a\|_2 = \sqrt{a_x^2+a_y^2+a_z^2}\]

이다.

줄여서 다음과 같이 표기하기도 한다.

\[|\boldsymbol a|\]

벡터 $(3,4,0)$의 크기를 직접 계산하면

\[\sqrt{3^2+4^2+0^2}=5\]

이다.

NumPy의 원소별 연산과 집계 연산을 이용할 수 있다.

a = np.array([3.0, 4.0, 0.0])

magnitude = np.sqrt((a**2).sum())
print(magnitude)

NumPy가 제공하는 np.linalg.norm()을 사용하면 더 간단하다.

magnitude = np.linalg.norm(a)
print(magnitude)

5. 스칼라와 벡터의 곱

벡터에 하나의 수인 스칼라 $c$를 곱하면 모든 성분에 $c$가 곱해진다.

\[c[\boldsymbol a] = \begin{bmatrix} ca_x\\ca_y\\ca_z \end{bmatrix}\] 
a = np.array([1.0, 2.0, 3.0])
scaled = 0.5 * a

print(scaled)

이는 앞선 NumPy 강의에서 배운 배열과 스칼라의 브로드캐스팅이다. 양의 값을 곱하면 방향은 같고 크기가 변한다. 음의 값을 곱하면 방향도 반대가 된다.

그림에서는 $\boldsymbol a=(2,1)$을 기준으로 배율을 비교했다. $\tfrac12\boldsymbol a=(1,0.5)$는 같은 방향으로 길이가 절반이며, $2\boldsymbol a=(4,2)$는 같은 방향으로 길이가 두 배다. $-\tfrac32\boldsymbol a=(-3,-1.5)$는 반대 방향이고 길이는 원래의 1.5배다. 이를 일반화하면

\[\|c\boldsymbol a\|=|c|\,\|\boldsymbol a\|\]

이다. 크기는 음수가 될 수 없으므로 배율의 절댓값을 사용한다. $c=0$이면 영벡터가 되며 방향은 정의되지 않는다.

6. 단위벡터

크기가 1인 벡터를 단위벡터(unit vector)라고 한다. 0이 아닌 벡터를 그 크기로 나누면 같은 방향의 단위벡터를 얻는다. 이처럼 벡터의 크기를 1로 맞추는 것을 정규화(normalization)라고 한다.

\[\widehat{\boldsymbol a} = \frac{\boldsymbol a}{\|\boldsymbol a\|_2}\] 
def unit_vector(vector):
    magnitude = np.linalg.norm(vector)
    if magnitude == 0:
        raise ValueError("zero vector has no direction")
    return vector / magnitude

a = np.array([3.0, 4.0, 0.0])
a_unit = unit_vector(a)

print(a_unit)
print(np.linalg.norm(a_unit))

영벡터는 방향이 없으므로 단위벡터로 만들 수 없다.

7. 내적

두 벡터의 내적(dot product)은 같은 위치의 성분을 곱한 뒤 모두 더한 값이다.

\[\boldsymbol a\mathbin{\cdot}\boldsymbol b = \sum_{i=1}^{n}a_i b_i\]

3차원에서는

\[\boldsymbol a\mathbin{\cdot}\boldsymbol b =a_1b_1+a_2b_2+a_3b_3\]

이다.

수식의 성분 번호는 1부터, NumPy 배열의 인덱스는 0부터 시작하므로 둘을 구분해야 한다. 즉, $a_1b_1+a_2b_2+a_3b_3$는 NumPy 코드에서 a[0]*b[0]+a[1]*b[1]+a[2]*b[2]에 해당한다.

a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 5.0, 6.0])

dot_product = (a * b).sum()
print(dot_product)

NumPy에서는 다음 두 표현을 사용할 수 있다.

print(np.dot(a, b))  # 내적
print(a @ b)         # 내적

여기서 @는 NumPy 배열의 행렬곱 연산자이며, a @ b는 np.matmul(a, b)와 같다. 이 예제처럼 두 배열이 길이가 같은 1차원 실수 배열이면, 대응하는 성분을 곱해 더한 내적을 계산한다. 따라서 (a * b).sum(), np.dot(a, b), a @ b의 결과는 모두 스칼라 32이다. 즉, $1\times4+2\times5+3\times6=32$이다.

반면 a * b만 계산하면 합을 하지 않으므로 내적이 아니라 원소별 곱 배열 [4., 10., 18.]이 나온다. @를 항상 내적 연산자로 해석해서는 안 된다. 두 배열이 2차원이면 행렬곱을 계산한다. 이 경우는 다음 12장에서 다룬다.

두 벡터가 모두 영벡터가 아니고 내적이 0이면 두 벡터는 서로 수직이다.

x_direc = np.array([1.0, 0.0, 0.0])
y_direc = np.array([0.0, 1.0, 0.0])

print(x_direc @ y_direc)

8. 두 벡터 사이의 각

내적은 두 벡터 사이의 각 $\theta$와 다음 관계를 갖는다.

\[\boldsymbol a\mathbin{\cdot}\boldsymbol b = |\boldsymbol a| |\boldsymbol b| \cos\theta\]

따라서

\[\theta = \cos^{-1} \left( \frac{\boldsymbol a\mathbin{\cdot}\boldsymbol b} {|\boldsymbol a||\boldsymbol b|} \right)\]

이다.

def angle_between(vect_a, vect_b):
    mag_a = np.linalg.norm(vect_a)
    mag_b = np.linalg.norm(vect_b)

    if mag_a == 0 or mag_b == 0:
        raise ValueError("zero vector has no direction")

    cosine = (
        vect_a @ vect_b
        / (mag_a * mag_b)
    )

    cosine = np.clip(cosine, -1.0, 1.0) ##최소 -1, 최대 1로 제한.
    angle_rad = np.arccos(cosine)

    return np.degrees(angle_rad)

a = np.array([1.0, 0.0, 0.0])
b = np.array([0.0, 1.0, 0.0])

print(angle_between(a, b))

결과는 90도이다. np.arccos()는 각도를 라디안(radian) 단위로 반환하고, np.degrees()는 이를 도(degree) 단위로 바꾼다. 부동소수점 오차로 코사인 값이 1을 조금 넘거나 -1보다 조금 작아질 수 있으므로, np.clip()으로 값을 $[-1,1]$ 범위 안으로 제한했다.

9. 외적

3차원 벡터의 외적(cross product)은 두 입력 벡터에 모두 수직인 벡터를 만든다. 두 벡터가 평행하면 결과는 영벡터다. 먼저 성분을 직접 계산하는 식을 익히자. 인덱스와 합산 기호를 이용한 표현은 13장 6.9절에서 다룬다.

\[[\boldsymbol a]\times[\boldsymbol b] = \begin{bmatrix} a_yb_z-a_zb_y\\ a_zb_x-a_xb_z\\ a_xb_y-a_yb_x \end{bmatrix}\] 
a = np.array([1.0, 0.0, 0.0])
b = np.array([0.0, 1.0, 0.0])

# manual calculation. # x->0; y->1; z->2
cross_prd=np.zeros(3)
cross_prd[0]=a[1]*b[2]-a[2]*b[1]
cross_prd[1]=a[2]*b[0]-a[0]*b[2]
cross_prd[2]=a[0]*b[1]-a[1]*b[0]

# np.cross 메소드를 사용하여 외적 계산
cross_prd = np.cross(a, b)
print(cross_prd)

결과는 $[0,0,1]$이다. 방향은 오른손 법칙을 따른다.

외적은 순서를 바꾸면 부호가 바뀐다.

\[\boldsymbol b\times\boldsymbol a = -\boldsymbol a\times\boldsymbol b\] 
print(np.cross(b, a))

외적의 크기는 두 벡터가 만드는 평행사변형(parallelogram)의 넓이이다.

\[|\boldsymbol a\times\boldsymbol b| = |\boldsymbol a| |\boldsymbol b| \sin\theta\]

그림에서 파란 벡터 $\boldsymbol a$를 밑변으로 잡으면 밑변의 길이는 $|\boldsymbol a|$이다. 빨간 벡터 $\boldsymbol b$의 끝에서 밑변에 수선을 내리면 높이는 $h=|\boldsymbol b|\sin\theta$가 된다. 따라서 넓이 $S$는

\[S=\text{밑변}\times\text{높이} =|\boldsymbol a|h =|\boldsymbol a|\,|\boldsymbol b|\sin\theta =|\boldsymbol a\times\boldsymbol b|\]

이다. 외적 자체는 벡터이고, 그 크기가 평행사변형의 넓이라는 점을 구분하자. 그림의 초록색 원 안의 점은 외적 벡터가 종이 밖, 즉 독자 쪽을 향함을 뜻한다. 이 방향은 $\boldsymbol a$에서 $\boldsymbol b$로 손가락을 감는 오른손 법칙으로 정한다. 순서를 바꾸면 외적의 방향은 반대가 되지만 넓이는 같다. 두 벡터가 평행하면 평행사변형이 선분으로 퇴화하여 넓이와 외적의 크기가 모두 0이 된다.

9.1. 내적·외적·원소별 곱 구분하기

연산 NumPy 표현 결과 대표적인 용도
원소별 곱 a * b 같은 길이의 배열 원소별 가중치 적용
내적 a @ b 스칼라 각도
외적 np.cross(a, b) 3성분 벡터 면의 법선, 넓이

여기서 외적은 cross product를 뜻한다. np.outer(a, b)가 계산하는 outer product는 $a_i b_j$를 성분으로 갖는 행렬이며 다른 연산이다. 평면 벡터의 외적을 구할 때도 이 자료에서는 $z$성분을 0으로 두어 3성분 배열로 입력한다.

외적의 방향은 입력 순서에 따라 달라진다. 평행한 두 벡터의 외적은 영벡터이므로, 그 외적을 정규화하여 면의 단위법선을 만들 수 없다.

10. 재료공학 예제

10.1. 두 힘의 합력

한 점에 두 힘이 작용한다고 하자.

force_1 = np.array([100.0, 0.0, 0.0])
force_2 = np.array([0.0, 50.0, 0.0])

resultant = force_1 + force_2
resultant_magnitude = np.linalg.norm(resultant)

print(resultant)
print(resultant_magnitude)

합력은 $[100,50,0]$ N이고 크기는 약 111.8 N이다.

10.2. 입방정에서 결정방향 사이의 각

입방정(cubic crystal system)에서는 결정방향 $[uvw]$를 성분이 $(u,v,w)$인 벡터로 다룰 수 있다. $[100]$과 $[110]$ 사이의 각을 계산해 보자.

direction_1 = np.array([1.0, 0.0, 0.0])
direction_2 = np.array([1.0, 1.0, 0.0])

angle_deg = angle_between(
    direction_1,
    direction_2,
)

print(angle_deg)

결과는 45도이다. 비입방정(non-cubic)에서는 격자벡터의 길이와 축 사이 각도를 반영해야 하므로, 방향 지수만으로 같은 계산을 할 수는 없다.

10.3. 평행사변형의 넓이

두 격자벡터가 만드는 평행사변형의 넓이는 외적의 크기로 구할 수 있다. 아래 예제에서는 두 벡터가 수직이므로 $\sin\theta=1$이며, 넓이는 두 벡터의 크기를 곱한 값이다.

lattice_a = np.array([2.0, 0.0, 0.0])
lattice_b = np.array([0.0, 3.0, 0.0])

area = np.linalg.norm(
    np.cross(lattice_a, lattice_b)
)

print(area)

넓이는 6이다. 격자벡터의 단위가 nm라면 넓이 단위는 nm$^2$이다.

10.4. 여러 변위벡터의 크기를 한 번에 계산하기

영상에서 추적한 세 점의 변위가 다음과 같다고 하자. 각 행은 한 점, 각 열은 $x,y,z$ 성분이며 단위는 $\mu\mathrm m$다.

displacements = np.array([
    [3.0, 4.0, 0.0],
    [0.0, 0.0, 2.0],
    [1.0, 2.0, 2.0],
])
lengths = np.linalg.norm(displacements, axis=1)
print(lengths)  # [5.0, 2.0, 3.0]

axis=1은 각 행의 성분을 모아 크기를 구한다는 뜻이다. np.linalg.norm(displacements)처럼 축을 생략하면 이 예제에서는 모든 원소의 제곱합에 제곱근을 취한 하나의 값이 나오므로, 점별 변위 크기와 구분해야 한다.

11. 자주 하는 실수

  • 두 벡터의 shape이 서로 다른데 성분별 연산을 시도한다.
  • $a * b$를 내적이라고 생각한다.
  • 영벡터를 크기로 나누어 단위벡터를 만들려고 한다.
  • 각도의 라디안(radian) 단위와 도(degree) 단위를 혼동한다.
  • 외적에서 벡터 순서를 바꾸어도 결과가 같다고 생각한다.
  • 배열 차원(ndim)과 물리학적 벡터 차원을 혼동한다.

12. 정리

  • 벡터는 1차원 NumPy 배열로 나타낼 수 있다.
  • 벡터의 합과 차는 같은 위치의 성분끼리 계산한다.
  • np.linalg.norm()은 벡터의 크기를 계산한다.
  • 단위벡터는 벡터를 그 크기로 나누어 구한다.
  • 내적 결과는 스칼라이며 두 벡터의 끼인 각과 관계된다.
  • 외적 결과는 두 입력 벡터에 모두 수직인 벡터이다.
